# Web Components Vite with v12 alpha enabled

This project is intended to serve as a reproduction starter for the Carbon Design System v12-alpha packages.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/carbon-design-system/sandboxes/tree/main/web-components/latest/vite-v12-alpha-enabled/?preset=node=)

## Running locally

1. Install dependencies

```sh
yarn install
```

2. Run it

```sh
yarn dev
```
